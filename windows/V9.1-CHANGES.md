# YORU V9.1 (0.9.1)

Separate release; V9 source and ZIP are preserved. User storage and home-catalog-v9.json remain unchanged.

- PlayerWindow.cs: replaces system window chrome with a two-row layout: a 48px custom title bar and the existing native VideoView/overlay. Uses WindowChrome for native drag, double-click maximize, system menu and resize hit testing. Windowed/maximized frames and fullscreen restore are handled separately; fullscreen removes caption height, border and resize chrome and restores the previous window state without reintroducing the system title bar. No transparent top-level video window or custom video rendering is added.
- Controls/PlayerTitleBar.xaml/.cs: #090C14 background, original YORU icon, constrained ellipsis title, shared CaptionButton style, localized accessible minimize/maximize-restore/close buttons and changing maximize/restore glyph. Controls remain at the standard right edge in both languages.
- WindowAppearance.cs: optional Windows 11 DWM corner preference for the player. Older Windows versions retain functional custom chrome; native rounded-corner support depends on the OS. No AllowsTransparency is used, preserving the native video surface.
- Controls/AnimeCard.xaml: year and genre borders align to their own measured content instead of stretching across the star-sized column. Both retain the same 7x3 padding, 11px text, 6px corners and 7px gap. The genre still truncates within available space on narrow cards. Shared AnimeCard is used throughout Home, Explore, Trending and catalog sections; poster dimensions, row layout and animation are unchanged.
- App.xaml.cs / V91Diagnostics.cs: diagnostic entry point and checks for badge geometry in EN/AR, five player window sizes, native H.264/AAC playback, minimize/maximize/restore/close, fullscreen restoration and translated controls.
- YORU.Desktop.csproj / Localization/strings.json / V8Diagnostics.cs: version 0.9.1 / Version 9.1 and metadata check. build.ps1 / README.md / VALIDATION.md: separate release documentation.

APIs, playback resolution, decoding options, media timing, watch history, startup cache, themes and existing main-window layout remain unchanged.
