# Components

- .NET / .NET for Android / Mono: Microsoft and contributors, MIT and component-specific notices.
- AndroidX RecyclerView, AppCompat and Media3 ExoPlayer/HLS/DASH/UI: Android Open Source Project, Apache 2.0.
- Kotlin/coroutines/serialization and Guava/AndroidX transitive dependencies: see each pinned NuGet package's license/notice metadata.
- Android SDK/build-tools/platform tools: Google Android SDK license terms; installed only as build tools, not shipped as SDKs inside this source archive.
- YORU logo: existing user-supplied Yoru2 artwork from the Windows project. Anime metadata/artwork and video hosts come from the existing application service and are not bundled as demo content.

Packages are pinned in the Android project and the local feed manifest under scripts. The application does not include the Windows LibVLC/WPF binaries, ad SDKs or a WebView wrapper. Full NuGet notices/licenses are available in each package in the toolchain cache and its upstream repository.
