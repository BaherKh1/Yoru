# YORU Android V1.0 — reference glass and Explore tap (90305)

Reviewed the provided navigation bar mockup again. The bar now has a darker, neutral-purple translucent base (#5C1C1C28), a softer gray/purple border (#387E748E), a restrained dark tint (#20181723), and a more visible purple selection surface (#4D8B5CF6). The frosted layer uses 38% opacity with 10dp GPU blur on Android 12+; older Android uses radius 2 on the existing one-fifth-size capture. Android 9+ additionally sets soft ambient/spot shadow colors. Pill dimensions, 24dp outer rounding, 25dp icons, labels, touch targets and 225ms selection movement are retained.

The glass surface is still retained per window, with no scroll/idle opacity, blur, tint or elevation updates. The low-opacity retained frost overlays live content visible through the translucent layers; it is not continuously sampled live blur. No per-scroll bitmap capture or new dependency is added.

Home and Explore now share the same native `HomeSmoothScroller` and interruption/deceleration behavior. Tapping the active Explore tab scrolls to item 0 with SnapToStart. Repeated taps do not restart an active animation; a drag or section change interrupts it. With system animations disabled, scrolling changes immediately. Selecting Explore from another bottom tab, or opening Search, resets its viewport and cached session position to 0 while retaining its query, sort, loaded results and API cache. Reselecting Explore does not rebuild the feed or issue API requests. A guarded top position survives asynchronous loading/layout commits; user dragging cancels that guard. Ordinary Back from details retains the existing catalog-return position.

Modified: `MainActivity.cs`, `FloatingNavigation.cs`, the reuse comment in `HomeSmoothScroller.cs`, and the package version code in `Yoru.Android.csproj`. Windows, APIs/resolver/player, episode snapshots, persistent settings/history/favorites, poster sizes and translations are unchanged. Install build 90305 over the existing app without uninstalling.

Validation: Release build, signature/package/ZIP checks and 12 existing portable core regression groups, recorded under `evidence/reference-explore-*`. No Android device is connected and the local emulator remains unavailable. Actual reference matching, visual scrolling and touch/inset behavior require device verification; no pixel-exact/device-tested claim is made.
